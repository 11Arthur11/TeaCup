# System Settings duration editor

صفحه `/admin/system` فرم تنظیمات برنامه را در یک `details` بسته نمایش می‌دهد. سه زمان حذف Resource در dialogهای کوچک ویرایش می‌شوند.

واحدهای قابل انتخاب:

- ثانیه: `value × 1,000`
- دقیقه: `value × 60,000`
- ساعت: `value × 3,600,000`
- روز: `value × 86,400,000`

مقدار نهایی به عدد صحیح میلی‌ثانیه تبدیل و در payload تغییرات قرار می‌گیرد. برای سازگاری با OpenAPI فعلی، کلید درخواست همچنان `suspendDeleteAfterSeconds` است؛ فقط معنای مقدار طبق قرارداد backend میلی‌ثانیه است.

همان منطق Patch-like قبلی حفظ شده است: فقط دوره تغییرکرده مقدار دارد و دوره‌ها یا بخش‌های تغییرنکرده `null` ارسال می‌شوند.
