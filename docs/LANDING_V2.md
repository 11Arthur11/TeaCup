# لندینگ اصلی ابر چایی

لندینگ جدید اکنون در مسیر اصلی `/` نمایش داده می‌شود. مسیر `/landing-v2` هم برای سازگاری با آدرس قبلی همین صفحه را نمایش می‌دهد. لینک بازگشت به نسخه کلاسیک از فوتر حذف شده است.

## اجرا

```sh
npm ci
npm run dev
```

سپس `http://localhost:4173/` را باز کنید.

```sh
npm run check
npm run build
```

خروجی استاتیک در `dist/` است. سرور میزبان باید برای مسیرهای SPA، فایل `index.html` را برگرداند. تنظیم آدرس API در `public/config.js` حفظ شده است.

## بازطراحی اخیر

- هیروی جدید با تیتر مرکزی «کنار هم، حتی از دور» و تصویرسازی اختصاصی اتصال TeaSpeak و AudioBot به ابر چایی.
- تصویرسازی با SVG و CSS، موج صوتی و حرکت مسیر اتصال؛ بدون وابستگی جدید یا پخش صدای واقعی.
- رعایت تم روشن/تیره، جهت RTL، نمایش موبایل و تنظیم کاهش حرکت سیستم.
- اصلاح ریشه مشکل هدر: `overflow: hidden` پوسته با `overflow: clip` جایگزین شده، مشابه لندینگ اولیه، تا هدر sticky همراه اسکرول پنجره باقی بماند.
- حفظ رفتار مشترک هدر و منوی موبایل؛ لینک‌های بخش‌ها با فاصله مناسب زیر هدر قرار می‌گیرند.
- لینک لوگو به `/` و به‌روزرسانی لینک امکانات در هدر صفحات عمومی؛ پشتیبانی از آدرس قدیمی `/#features`.
- فوتر فقط لینک محصولات و قوانین خدمات دارد؛ لینک نسخه کلاسیک حذف شده است.
- سایر بخش‌های تأییدشده شامل سرویس‌ها، امکانات، مراحل شروع، فهرست محصولات API، FAQ و دعوت به خرید حفظ شده‌اند.

کد صفحه در `src/pages/landing-v2.ts` قرار دارد. استایل‌های این صفحه با پیشوند `lv-` و `.public-shell--v2` محدود شده‌اند. مسیر اصلی در `src/main.ts` به همین رندرکننده متصل است.

## بررسی

- `npm run check` و `npm run build` موفق.
- تست مرورگری در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل، در تم روشن و تیره؛ بدون اسکرول افقی.
- بررسی موقعیت هدر در بالای صفحه، اسکرول ۵۰۰ و ۱۶۰۰ پیکسل و انتهای صفحه: هدر در بالای پنجره باقی می‌ماند.
- بازشدن منوی موبایل در موقعیت صحیح بعد از اسکرول، عملکرد Escape و ناوبری بخش‌ها.
- بررسی مسیر اصلی، مسیر سازگار `/landing-v2`، لوگو، دکمه محصولات و لینک امکانات از صفحه محصولات.
- بدون خطای اجرای JavaScript در تست مرورگری.

API در تست‌ها شبیه‌سازی شده است؛ خرید یا پرداخت واقعی انجام نشده است. تصاویر و گزارش بررسی اخیر در `docs/landing-v2-preview/` قرار دارند. قیمت‌های موجود در تصاویر صرفاً داده آزمایشی‌اند؛ خود صفحه محصولات را از API فعلی پروژه دریافت می‌کند.

## لودینگ فنجان چای

همان لودینگ HTML/CSS نسخه اولیه، با انیمیشن بخار و متن «در حال دم کردن چای...» به صفحه اصلی و مسیر `/landing-v2` اضافه شده است. مارک‌آپ و کنترل‌کننده از `landing.ts` مشترک استفاده می‌شوند؛ ظاهر و استایل قبلی حفظ شده‌اند.

لودینگ حداقل ۷۲۰ میلی‌ثانیه نمایش داده می‌شود و پس از آماده‌شدن فونت‌ها و رندر اولیه محو می‌شود. انتظار فونت حداکثر ۲٫۵ ثانیه است تا اختلال دریافت فونت صفحه را قفل نکند. نمایش لودینگ به پاسخ API وابسته نیست. هنگام جابه‌جایی مسیر، کنترل‌کننده لغو و قفل اسکرول آزاد می‌شود؛ پیوند مستقیم بخش‌ها پس از بسته‌شدن لودینگ به جای درست اسکرول می‌کند.
