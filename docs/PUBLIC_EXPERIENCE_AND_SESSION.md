# Public experience and session flow

## Session

- `HEAD /v1/auth/session` تنها معیار تشخیص نشست فعال است.
- `204`: نشست فعال؛ سپس `/v1/users` برای نقش و پروفایل خوانده می‌شود.
- `401`: کاربر مهمان است.
- ورود به `/auth` نیز ابتدا همین endpoint را بررسی می‌کند و کاربر واردشده را به داشبورد مناسب می‌فرستد.
- هیچ session hint در storage مرورگر استفاده نمی‌شود.

## Public routes

- `/`: Landing بازطراحی‌شده ابر چایی
- `/products`: محصولات عمومی mock تا آماده‌شدن API عمومی
- `/rules`: نسخه اولیه قوانین استفاده

اطلاعات محصولات عمومی عمداً mock و با برچسب «نمونه نمایشی» مشخص شده‌اند.
